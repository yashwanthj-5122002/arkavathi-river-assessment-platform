ARKAVATI PRODUCTION DATA
========================

1. showcase_videos\
   Copy approved MP4/MOV/M4V/WEBM videos here to show them on the application's video showcase.
   No frontend rebuild is required. The application generates the playlist dynamically.

2. video_srt_pairs\
   Put operational Video + SRT pairs here, preferably grouped by survey date:

   video_srt_pairs\23-08-26\DJI_0008.MP4
   video_srt_pairs\23-08-26\DJI_0008.SRT

   Segmented videos are supported, for example:
   DJI_0015-006.MP4 + DJI_0015.SRT

   After copying files, log in -> Street View -> Video + SRT -> Server Media Library -> Refresh Library.

3. imports\
   Staging area for approved import packages before using the application's import scripts.

4. backups\
   Default location for timestamped production backups.

Do not place API keys or passwords in this folder.
